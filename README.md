# Bharathkumar Y — Portfolio

A premium, responsive, recruiter-friendly portfolio for Bharathkumar Y.

## Run in VS Code
1. Open this folder in VS Code.
2. Open `index.html`.
3. Right-click → **Open with Live Server**.

## Files
- `index.html` — portfolio structure/content
- `style.css` — responsive premium dark UI
- `script.js` — menu and reveal interactions
- `images/profile.jpeg` — profile photo
- `assets/Bharathkumar_Y_Java_Developer_Fresher_Resume.pdf` — resume
- `assets/projects/` — local project visuals

## Important
The project visuals are original local SVG illustrations, not copied website screenshots. Replace them with real screenshots later if you have them.
